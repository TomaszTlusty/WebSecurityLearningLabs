Web Security Labs

Interactive platform for learning web vulnerabilities through hands-on labs and guided UI/UX experiences. Built with a frontend-first approach for the competition, focusing on engaging and accessible labs to help understand common web security concepts.

Tech Stack
- Next.js
- TypeScript
- Tailwind CSS

Features
- Interactive Vulnerability Labs
- Modern and professional UI
- Responsive Design
- Frontend-first implementation optimized for rapid iteration
- Clear presentation of lab content and learning flows

Setup
- Install dependencies:
npm install
- Start the development server:
npm run dev
